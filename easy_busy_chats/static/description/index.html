EasyBusy Chats

Unified messenger conversations inside Odoo

EasyBusy Chats adds a dedicated chat workspace to Odoo and lets users work with messenger conversations without leaving the backend.

Key Features

  • Dedicated Chats menu inside Odoo.
  • Per-user EasyBusy token and company configuration.
  • Link a conversation to an existing contact.
  • Create a new contact directly from the chat panel.
  • Store messenger chat links on the partner form.
  • Open the original chat from Odoo with a direct link.

Supported Channels

  • Telegram
  • WhatsApp
  • Viber
  • Facebook Messenger
  • Instagram
  • Website chats

External Service

This module integrates with the EasyBusy external SaaS platform: https://easy-busy.chat/

A paid EasyBusy subscription may be required. User data, including access tokens and chat-related information, may be transmitted to EasyBusy servers for processing.

The module loads an external JavaScript chat client from EasyBusy infrastructure.

Configuration

  1. Install the module.
  2. Assign the EasyBusy Chats user group to the required users.
  3. Open user preferences and fill in the EasyBusy access token.
  4. Select the EasyBusy company for the current user.
  5. Open the Chats menu and start linking conversations.

Technical Notes

This addon depends on base_setup and adds security, user preferences, partner chat history, and the EasyBusy chat client action.
