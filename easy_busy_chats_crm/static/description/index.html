EasyBusy Chats CRM

Convert messenger conversations into CRM opportunities

EasyBusy Chats CRM extends the EasyBusy chat integration with an opportunity creation wizard available directly from the chat panel.

What This Addon Adds

  • Create a CRM opportunity from a conversation.
  • Assign the opportunity to a salesperson and sales team.
  • Link the opportunity to an existing customer.
  • Create a new customer during the opportunity conversion flow.
  • Detect duplicate opportunities by customer, phone, or email.
  • Merge existing opportunities instead of creating duplicates.

Workflow

  1. Install easy_busy_chats and crm.
  2. Install this addon.
  3. Open a conversation in EasyBusy Chats.
  4. Use Create Opportunity from the available chat actions.
  5. Create a new opportunity or merge duplicates when needed.

Dependencies

  • easy_busy_chats
  • crm
