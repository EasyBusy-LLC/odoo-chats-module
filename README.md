# EasyBusy Chats for Odoo

Integrate EasyBusy live chat into your Odoo system and manage all customer conversations in one place.

---

## Overview

EasyBusy Chats allows you to connect your Odoo instance with the EasyBusy SaaS platform and handle all incoming customer messages directly from your website and CRM.

All chats, leads, and interactions are centralized, helping you respond faster and never lose potential customers.

According to EasyBusy positioning, the goal — “all chats in one window” and instant replies with no lost leads.

---

## Features

- Website live chat widget
- Centralized chat inbox
- CRM integration (link chats to leads)
- Real-time notifications
- Easy installation and setup
- External chat widget loader (JS integration)

---

## How It Works

1. Install the module in Odoo
2. Create an EasyBusy account: https://easy-busy.chat/
3. Get your API token
4. Connect Odoo to EasyBusy
5. Start receiving chats

---

## Requirements

- Odoo 17.0
- Internet connection
- EasyBusy account

---

## Installation

1. Download or clone the repository
2. Place the module in your Odoo addons folder
3. Update Apps list
4. Install **EasyBusy Chats**

---

## External Service (Important)

This module integrates with an external SaaS service:

- Service: https://easy-busy.chat/
- A paid subscription may be required
- User data (such as API tokens) is transmitted to EasyBusy servers for processing

Make sure to review the Privacy Policy and Terms of Service on the EasyBusy website.
